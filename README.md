# Z/LOG

Personal push / pull / legs training log. A single-page web app that installs to the iPhone home screen and works offline.

- `index.html`: the whole app (styles, logic and font embedded)
- `sw.js`: offline support
- `manifest.webmanifest` + `icons/`: home-screen install

Data is stored on the phone (browser storage). Use **Setup → Backup → Save backup file** every week or two.
